# 配音工作台

双击 `启动配音工作台.vbs`，在弹出的窗口中选择视频项目根目录，例如 `D:\Desktop\video_producing\project\公开数据A`。工作台右上角可随时切换项目。首次使用前，确保此电脑已能运行 Node.js 与 ffprobe。

点击右侧“清除当前项目配音”可删除该项目工作台生成的配音、时间戳及音频清单，并重置草稿里的音频状态。操作前会提示确认；口播文字和视频画面保留，已删除的配音不能恢复。

项目根目录需要包含 `script/script.md` 和 `production/remotion`。画面字幕自动对齐还要求该项目已有对应的字幕提取和对齐工具；没有工具的项目仍可使用脚本分段配音。各项目草稿保存在各自的 `production/配音工作台`，音频保存在各自的 Remotion 项目内，互不覆盖。

## 按现有画面字幕自动对齐

1. 点击左下角“导入画面字幕并对齐”。工具从所选项目的 Remotion 源码（`production/remotion/src`）中提取字幕文字、场景顺序及起止帧，并保存在所选项目 `production/配音工作台/subtitle-segments.json`；原来的 `segments.json` 草稿不受影响。
2. 填写 API Key、音色和语速，先生成并试听几段。可在工作台编辑某句配音文字；对齐预览会同时显示编辑后的文字。
3. 点击“生成全部待处理片段”。全部成功后自动将配音及对应文字接入视频预览；也可在全部生成后点击“创建画面配音对齐预览”。
4. 在 Remotion Studio 打开配音版合成（`VideoDubbed`），播放并检查。原有无声版本保持不变。

对齐规则：每段从对应原画面节拍开始；如果声音超过该字幕的原始窗口，自动延长该段并将原有画面动作分配到延长后的窗口，后续画面依次后移。音频不会被裁切或加速，但总片长可能超过四分钟；短音频会保留原本剩余时间。字幕以每个画面节拍为单位同步，不保证逐字口型或语音与每个动作精确同步。

声音设置里的“预设音色（2.0）”选自 [火山引擎官方音色列表](https://docs.volcengine.com/docs/doubao-voice/tone-list-3?lang=zh)，选择名称后自动填写 ID；也可手动输入新音色 ID。音色目录是本地快照，实际可用性取决于账号权限与官方更新；当前接口固定使用 `seed-tts-2.0`，不要输入其他模型的音色 ID。

字幕解析当前针对项目中静态定义的 `caption`/`cue` 和固定 `Sequence`；无法读取时会报错，不会凭空推测。若后来修改视频中的字幕或时间，点击“刷新画面字幕时间轴”：工作台会先备份字幕工程，按稳定节拍编号保留来源文字未变片段的编辑和配音；即使起止时间变化，配音也可复用，再重新生成受影响配音。创建预览时会验证字幕及时间是否仍和视频源码一致。当前字幕是画面短句，可能不同于完整 `script.md` 口播稿。批量生成会逐段调用语音服务并产生相应用量。

## 原有脚本分段模式

1. 在火山引擎豆包语音控制台开通语音合成 2.0，获取 API Key 和音色 ID。
2. 在工作台右侧填写 API Key 和音色 ID，选择语速。Key 仅保留在当前程序会话的内存中，不写入工作台项目文件。
3. 左侧选择片段，中间编辑文本并保存；点击“生成当前段”或“生成全部待处理片段”。点击生成才会向火山引擎发送文本并产生相应服务用量。
4. 试听每个片段；调整文本、音色或语速后，原音频会标记为过期，需要重新生成。
5. 全部分段生成完毕后点击“生成 Remotion 音频清单”。清单按真实音频时长顺序排列，默认片段间留 0.35 秒；它尚不会修改视频画面或自动校准字幕。

脚本分段草稿保存在所选项目的 `production/配音工作台/segments.json`；音频、时间戳和 `manifest.json` 位于项目的 `production/remotion/public/audio/voice-workbench/`。原始脚本 `script/script.md` 不会被覆盖。单段重生成成功后覆盖该段旧音频，失败时保留旧音频。

接口返回的时间戳受服务和音色支持情况影响：可能为空；空时间戳不表示已完成字幕对齐。检查最终总时长，若与既定视频长度不一致，需要调整口播、停顿或画面，而不能假设已自动对齐。
