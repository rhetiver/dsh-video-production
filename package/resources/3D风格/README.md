# 3D 风格

三套风格长什么样，**给人挑的**。

执行时不要读这里——判断规则、参数、坑全在 `templates/three-kit/README.md`（新建项目后是 `scripts/three-kit/README.md`），那一份就够。

| 编号 | 风格 | 一句话 | 样张 |
|---|---|---|---|
| s1 | 浅场等距 | 明亮纸面 + 纯色平涂 + 倒角，靠形状说话 | [poster](<#s1 浅场等距/three-poster.png>) |
| s2 | 暗场展台 | 黑场 + 一盏聚光 + 一颗光点，靠光的衰减说话 | [poster](<#s2 暗场展台/three-poster.png>) |
| s3 | 夜城边光 | 黑体 + 暖金棱线 + 距离分层，靠轮廓说话 | [poster](<#s3 夜城边光/three-poster.png>) |
