# 制作台

## 你要判断的四件事

| # | 要定什么 | 看哪里 | 定了之后跑什么 | 落到哪个文件 |
|---|---|---|---|---|
| 1 | 稿子、章节、时长 | `project/<名>/script/script.md` | `node scripts/script-to-beats.cjs` | `content/beats.txt` + `beats.json` |
| 2 | 2D 画风 | 双击 `风格画廊.url`（86 套，看 poster） | `node templates/new-video-project.cjs --name <名> --style 55` | `style/tokens.css` |
| 3 | 3D 点缀风格 | `3D风格/#s1` `#s2` `#s3` 里的 poster | 用 Three.js 创建场景，在清单登记并在 Remotion 时间线上引用 | `production/remotion/src/` |
| 4 | 要不要出成片 | 配音完成后，在 `production/remotion` 运行 `npm run timeline` 和 `npm run dev`，在浏览器的 Remotion Studio 查看 `VideoDubbed` 完整预览 | 预检完成、你批准后运行 `npm run render:dubbed` | `dist/*.mp4` |

**中间阶段不落视频文件**：关键帧出 PNG，动效短样和灰模都在 `npm run dev` 的 Remotion Studio 里播（左侧选 KF1 / KF2 / KF3 / Sample / Gray）。只有停点 3 你点头后才渲染 mp4 到 `dist/`。

配音：`配音工作台/启动配音工作台.vbs` → `npm run cues` → 录音 → `npm run timeline`

## 这些东西各自对应哪个脚本

| 你看到的 | 脚本 |
|---|---|
| 86 套 2D 风格 | `skills/claude-opus-5-5-new/scripts/style-tokens.cjs`（把选定风格提取成 tokens） |
| 三套 3D 样张 | `3D风格/`，新项目内置 Three.js 版本 |
| 3D 场景 | `production/remotion/src/components/ThreePreset.tsx`；运行 `node scripts/lint-accents.cjs` 检查 |

新建项目后，上面 `templates/` 和根 `scripts/` 的路径换成项目内的 `scripts/`。

## 三个停点（只在这三处找你）

1. **稿子** — 章节数、时长、素材，确认后才开工
2. **关键帧 + 灰模** — 风格立不立得住、节奏对不对，通过后才做美术
3. **出片** — AI 先按 [Studio 成片预检](AGENTS.md)检查、修复并提供预览；只有你点头才渲 MP4

其余时间 AI 自己跑，不打断你。
