# Three.js 3D 点缀

选点、密度规则与可调用的 Three.js 三套预设。**执行时只需要读这一份**，不用再跳别的文件。

---

# 一、什么时候该加

目标是只在平面讲不清的地方放，不是多放。每一章都要表态：要么给选点，要么写「无」+ 理由。

## 五个信号（命中 2 个才做）

1. **空间关系**：里 / 外、穿过、包围、层叠、一端到另一端——二维图要么画不清，要么画得像示意图
2. **量级**：成千上万、指数增长、铺满整面墙——需要“多到数不清”的证据，而不是一个“很多”的形容词
3. **同一物的多状态**：拆开、剖开、堆叠、展开、归零
4. **尺度对比**：一粒 vs 一栋楼，一秒 vs 十年
5. **章节入口**：新概念第一次出现，先给一个“这是什么地方”的镜头

## 五个反信号（命中任意一条就别做）

1. 要出现具体文字、数字、公式——改一句文案就要重渲，交给 Remotion
2. 内容本身是流程或因果——箭头和连线快十倍也更清楚
3. 画面里需要精确读数——图表、时间轴、对比条，一律二维
4. 只是“想让它动起来”——删掉后信息不少，那是装饰，用 CSS
5. 落在全片字幕最密的三拍里——观众在读字，没空看画面

## 讲什么，参考哪种样张

| 内容类型 | 编号 | 画面 |
|---|---|---|
| 一个具体场景里发生的事：教室、工位、车间、流水线 | `s1` 浅场等距 | 俯视一间屋子，人和物按格子排开 |
| 代价、风险、临界、一个决定压下来 | `s2` 暗场展台 | 黑场里一个东西被一盏灯照着 |
| 规模、网络、集群、城市、时间跨度 | `s3` 夜城边光 | 无数体块，只有轮廓在发光 |

一句话记：**有人的地方用 s1，有代价的地方用 s2，有数量级的地方用 s3。**

## 放哪一拍（按优先级）

1. 章节第一拍——建立空间
2. 机制里看不见的那一步——“数据在内部流动”这类无法拍摄的动作
3. 量级或对比出现的那一拍
4. 章节收尾的定格

两条经验：**选两极不选中间**（信息最密的拍给结构，最空的拍给呼吸，中间那些“有点内容”的最不该上 3D）；**一节最多两个，相隔 ≥20 秒**，连放三个观众就开始等画面。

## 密度

| 项 | 值 |
|---|---|
| 每 60 秒 | 1–2 个 |
| 单个时长 | 2–5 秒；>6 秒它已经是主镜头 |
| 相邻起点 | ≥ 20 秒 |
| 全片占比 | ≤ 12% |

## 一个反例

“哈希把任意长度压成固定长度”——看着适合三维，但画面必须出现那行字和两串十六进制。字一进三维就锁死，改文案要重渲；这条用 Remotion 画二维漏斗反而更准。

# 二、制作与交接

使用 @remotion/three 的 ThreeCanvas，动画用 useCurrentFrame() 按帧计算。材质颜色取自项目令牌，文字数字留在 Remotion 层。加载资源时等待完成，确保逐帧可复现。

清单条目：{id, tool: "three", path, from, to, alpha}，path 是项目内场景组件路径。还须在 Remotion 时间线上引用组件；清单不会自动加载。运行 node scripts/lint-accents.cjs 检查路径、区间和密度。

新项目已包含 production/remotion/src/components/ThreePreset.tsx。调用示例（在 Remotion 画面中，时间区间与清单一致）：

```tsx
import {Sequence} from 'remotion';
import {ThreePreset} from './components/ThreePreset';

<Sequence from={120} durationInFrames={90}>
  <ThreePreset style="s1" motion="push" motionAmount={0.5} durationInFrames={90} />
</Sequence>
```

style 可选 s1 / s2 / s3；motion 可选 none（默认）或 push；motionAmount 是相机推进距离。durationInFrames 应与 Sequence 相同，决定推进的完整时长。颜色取 style/tokens.css 的 --three-c* 令牌，须按全片风格调整。三套场景为带背景的不透明画面，登记 alpha: false；暂不提供更多参数接口、透明输出及 s3 多机位。新场景先做关键帧与短样，检查色彩、遮挡、清晰度和帧驱动。渲染 WebGL 时按 Remotion 版本和环境配置 Chromium GL。
